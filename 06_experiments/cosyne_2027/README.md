# COSYNE 2027 evidence and run index

This is the entry point for the [two-page abstract outline](../../99_inbox/cosyne%202027%20abstract.md). The [training attempt catalog](training_runs.csv) joins old and new production runs by explicit family, seed, factors, StudySpec fingerprint, job ID, replacement lineage, and NEMO2 run directory. The [frozen-policy evaluation catalog](frozen_policy_evaluations.csv) joins all 54 own-policy/random-policy probes to their nine September parent checkpoints. Regenerate both with `python -m 06_experiments.cosyne_2027.build_run_index` from the repository root.

The CSVs contain paths and provenance, not copied checkpoints. Bulk checkpoints and raw telemetry stay in their original NEMO2 workspaces. Existing lightweight result tables and selected figures are linked below, so the evidence can be opened from this page without searching old batch folders.

The catalog has **104 training attempts**: 9 historical, 51 earlier ablation, 40 fresh original, and 4 replacement attempts. Four failed originals are retained only for audit; they must be excluded from effect estimates. The two completed earlier replacements have 100M checkpoint files and Slurm exit zero; the two fresh replacements were still running at the 11 October check. Thus, 98 attempts have verified 100M endpoints, with two scientific C15 cells still pending. The `attempt_status` field is a dated snapshot, not live scheduler state.

The September source checkout is unavailable, so old-intact versus corrected-core ablation comparisons remain cross-source. The first/later ablation controls also used smaller constant encoder credit than the newly calibrated mean-matched arms. Pool or compare them only with those boundaries visible. Replacement source patches change the learner only in minibatches that would otherwise fail; keep their source tag in every analysis.

## How to use this index

Filter `training_runs.csv` by `family`, `encoder_credit`, `worker_bonus`, and `seed`; use `attempt_status` and `replaces_job_id` to exclude failed originals. `study_path`, `schema`, `workflow_version`, and `study_sha256` identify the validated definition. `submitted_manifest` points to the archived command and job record. `run_dir` points to the original NEMO2 output; the September rows use the retired historical allocation, which is read only. The 54 rows in `frozen_policy_evaluations.csv` are repeated evaluation seeds and policies attached to nine parent training seeds, not 54 independent training replicates.

For the next analysis, collect each completed fresh StudySpec through the [canonical workflow](../../04_implementation/standardized_study_workflow.md), join standardized outputs to this catalog by study ID and run identity, then render the full architecture-by-manipulation panel with missing cells visible. Keep paired seed as the unit of inference. The [workflow status](../../hpc_runs/intrmotiv_study/LATEST.md) and [analysis availability issue](../../infra.md#validate-analysis-availability-before-a-batch-collection--2026-10-10) explain why mixed C01/C05/C15 collection may need family-specific analysis declarations while preserving the original training fingerprints.
