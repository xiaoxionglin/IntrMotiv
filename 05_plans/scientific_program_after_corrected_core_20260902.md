# IntrMotiv Scientific Program After The Corrected-Core Re-evaluation

## Decision summary

The next phase should narrow the paper rather than add another layer of
navigation machinery.

The central scientific claim to test is:

> Intrinsic propagation in a sparse DG/CA3-like sequence system can provide an
> endogenous teaching signal that selects landmark-like sensory events and
> shapes exploration before external task reward is available.

Lin, Yiu, and Leibold show that sparse egocentric input and a hippocampus-
inspired sequence generator synergize under task reward, producing localized
spatial representations and supporting maze navigation. IntrMotiv should not
re-claim that result. It asks whether the temporal state generated by the same
minimal motif can itself train the sparse input and behavior, and whether the
resulting representation is useful for later navigation.

The corrected-core batch supports continuing this question, but it does not
support making a full HRL planner the paper's central result. DG populations
remain active and some conditions explore broadly, while target-conditioned
control remains weak. That separation is scientifically informative: landmark
formation, exploration, graph construction, and intentional landmark reaching
are distinct capabilities.

## Relationship to Lin et al.

The current predecessor is arXiv:2510.09951v3, now titled *Emergence of Spatial
Representation in an Actor-Critic Agent with Hippocampus-Inspired Sequence
Generator* and accepted at ICLR 2026.

| Question | Lin et al. | IntrMotiv paper question |
|---|---|---|
| Source of behavioral value | External task reward | Internal DG/CA3 transition structure before task reward |
| Role of sparse input | Supports sequence memory and task navigation | Also becomes a learned set of intrinsically selected events |
| Role of sequence dynamics | Long-horizon memory for sparse evidence | Memory plus source of delayed intrinsic feedback |
| Spatial representations | Emerge during rewarded task learning | Form during reward-free exploration and are tested for later utility |
| Main causal test | Sparsity x memory architecture and sequence length | Structured sequence feedback x encoder learning x policy learning |
| Downstream question | Can the agent solve the rewarded maze? | Does intrinsic pretraining improve later task learning or landmark utility? |

The one-sentence novelty should remain stable across the paper:

> Lin et al. use hippocampal sequence dynamics to support externally rewarded
> navigation; we test whether those dynamics can generate their own feedback
> for organizing landmarks and exploration before reward defines a goal.

## What the corrected batch changes

### Positive evidence

- All corrected cells maintain an active sparse DG population online.
- C12/C13 offline probes show spatially differentiated, non-collapsed DG maps.
- C15's frontier scoring produces a large, seed-replicated coverage increase.
- Several simpler direct cells, especially C05-C07, produce target-hit lift
  modestly above a shuffled-target reference.

### Negative or limiting evidence

- High graph coverage does not imply that the worker obeys the target.
- C15 has the best physical coverage but target-hit lift below one and almost
  zero action sensitivity.
- Long deadlines raise option completion without proving intentional control.
- C13 recovery degrades target-conditioned control relative to C12.
- Waypoints, HER, and greater manager complexity do not monotonically help.
- Sampled trajectories contain repeated circles and low-displacement periods.

The correct inference is not that the sparse-sequence idea failed. It is that
the current batch combined four questions that must now be separated:

1. Does sequence-derived feedback organize DG events?
2. Does it improve reward-free exploration?
3. Are the events useful landmarks?
4. Can a goal-conditioned worker deliberately reach them?

The paper can succeed on the first three without claiming that the fourth is
already solved.

## Core, probes, and borrowed ideas

To preserve conceptual uniqueness, every new mechanism should be assigned one
of three roles before implementation.

### Core contribution

- Frozen pretrained egocentric visual features.
- Learned sparse DG-like event projection.
- Intrinsic CA3-like sequence propagation.
- Transition-aligned endogenous feedback to representation and behavior.
- Closed-loop interaction between event selection, sequence memory, and
  behavioral sampling.

Only mechanisms necessary to test this loop belong in the main model.

### Scientific probes

- Place-field maps and fixed-observation reliability tests.
- Physical pose and trajectory geometry used only during evaluation.
- Behavioral-loop and reward-inside-loop telemetry.
- Linear decoding, graph-reachability prediction, and downstream transfer.
- A simple target-conditioned worker as a landmark-utility readout.

Probes may use privileged information as long as it never enters training and
the paper labels it as evaluation.

### Comparators or future work

- SLAM pose graphs and visual odometry.
- UCB frontier management.
- HER and goal relabeling.
- Explicit latent-world-model graphs such as L3P.
- Successor representations, replay planning, and differentiable graph search.

These works can motivate controls and discussion. They should not all be
incorporated into IntrMotiv. Doing so would turn a testable hippocampal motif
into an unidentifiable collection of standard navigation modules.

## Paper-defining experimental program

### Stage 1: close measurement-critical implementation boundaries

Before the next causal batch:

1. Make actor and learner DG normalization behavior-identical. This is the
   remaining critical semantic confound because it changes which events cross
   threshold during behavior and replay.
2. Keep the ImageNet trunk frozen and verify its checksum at initialization and
   checkpoint load.
3. Keep post-optimizer unit-row projection and valid-only recruitment tests.
4. Add first-achievement semantics if HER remains in the code, but remove HER
   from the paper's core experiment unless a later clean ablation justifies it.
5. Add loop telemetry without changing reward or action selection: repeated
   action runs, contextual DG cycles, physical closure for evaluation, reward
   accumulated inside loops, and escape latency.
6. Treat event-count normalization as an explicit ablation, not an invisible
   repair, because it changes the effective encoder learning rate.

### Stage 2: isolate the endogenous sequence-learning loop

Run a small pilot before a paper-scale batch. The cleanest design is a 2 x 2
factorial in the simple non-HRL agent:

| Cell | Encoder receives sequence feedback | Policy receives intrinsic reward | Purpose |
|---|---:|---:|---|
| Full IntrMotiv | yes | yes | Complete closed loop |
| Representation only | yes | no | Can feedback form landmarks under entropy-driven sampling? |
| Behavior only | no | yes | Can a fixed sparse code drive exploration without adaptive landmark selection? |
| Neither | no | no | Matched reward-free control |

The encoder-off condition should use a fixed, seed-matched sparse projection,
not a different visual architecture. The policy-off condition should retain the
same entropy regularization and optimizer budget.

Add one sequence-structure control after this pilot is numerically healthy:

- preserve DG event rate and reward marginal distribution;
- destroy the correspondence between current events and their actual CA3
  temporal context by a preregistered temporal or feature permutation;
- keep policy capacity and observation input unchanged.

This is a stronger causal test than adding another manager. If the full model
outperforms the shuffled control in both representation and coverage, the
effect can be attributed to structured sequence relations rather than generic
reward noise, sparsity, or parameter count.

Use three seeds for the pilot and at least five independent seeds for the final
selected comparison. Report individual seeds and confidence intervals; do not
select conditions from seed 99 alone.

### Stage 3: establish that the learned events are landmarks

The representation claim needs more than active units or visually appealing
maps. Pre-register:

- active and silent units;
- spatial information with occupancy controls;
- active-only map cosine and pre-threshold map cosine;
- peak diversity;
- split-half and cross-episode reliability;
- number of disconnected fields per unit;
- contextual false-match rate for multi-location DG units;
- stability on a fixed observation panel or scripted trajectory;
- robustness across withheld spawn points, textures, or layouts.

A useful landmark should be selective, repeatable, and discriminable from
other landmarks. Perfect single-place fields are not required if recent
sequence context reliably disambiguates multiple fields.

### Stage 4: test behavioral exploration without hiding proxy exploitation

Primary behavioral outcomes should remain external to the intrinsic objective:

- coverage AUC and unique cells in matched 900-decision episodes;
- occupancy entropy;
- path diversity across episodes;
- fraction of time in repeated circles or near-static behavior;
- intrinsic reward earned inside versus outside repeated loops;
- coverage on withheld layouts.

Do not add a loop penalty until telemetry shows that repeated cycles are a
major source of intrinsic return. If intervention becomes necessary, first test
a mechanism native to this model: habituation of repeatedly traversed
contextual DG-transition motifs. That uses the system's own sequence memory and
tests a principled prediction. A full metric SLAM subsystem or learned visual
odometry model should remain a separate comparison unless the paper's question
is deliberately changed.

### Stage 5: make the strongest bridge to Lin et al. through transfer

The most compelling downstream test is not necessarily autonomous HRL. It is a
two-phase experiment:

1. Pretrain without environmental reward using IntrMotiv.
2. Introduce one or more navigation tasks and measure rewarded learning.

Compare:

- Lin-style task learning from scratch;
- IntrMotiv pretraining followed by task learning;
- matched entropy/random pretraining followed by task learning;
- optionally one established intrinsic-motivation pretraining baseline, kept
  external rather than merged into IntrMotiv.

Test both a frozen-representation transfer and a fine-tuned transfer. Primary
outcomes are task sample efficiency, final success, and generalization to new
goals or layouts. This directly extends the predecessor: sequence dynamics no
longer only help after reward is present; their intrinsic organization is
tested for value before reward.

### Stage 6: retain HRL as a secondary landmark-utility experiment

The manager graph is useful as a probe: can emergent events support local
reachability and compositional navigation? It should advance only after a
worker passes a simple target-control benchmark.

Required gate:

- target-hit lift above one in most seeds and in the mean;
- increased action sensitivity under alternative targets;
- target-only option success not explained solely by longer deadlines;
- performance on held-out source-target pairs;
- lower time-to-hit than an unconditioned policy.

Until this gate passes, do not add more waypoint, pose-graph, curvature, or
loop-closure machinery to the training architecture. C15 can remain an
interesting exploration comparator, and its negative dissociation between
coverage and control belongs in the paper or appendix.

## Decision rules

Advance the central claim only if the full intrinsic model beats its matched
sequence-shuffled and closed-loop component controls on both:

1. at least one preregistered landmark-quality outcome; and
2. reward-free physical coverage or downstream task learning.

If representation improves without behavior, frame the result as intrinsic
landmark formation rather than intrinsic navigation. If behavior improves
without representation, the policy may be exploiting the reward proxy. If
neither improves relative to controls, do not rescue the claim by adding a
generic planner; revise the transition-distance hypothesis.

## Intended paper structure

1. Lin et al.: sparse input and sequence memory support rewarded navigation.
2. Hypothesis: intrinsic sequence state can also teach event selection before
   reward.
3. Minimal IntrMotiv mechanism and temporal credit assignment.
4. Causal component and sequence-structure ablations.
5. Landmark representation and reward-free exploration results.
6. Loop/proxy-exploitation analysis.
7. Downstream rewarded-transfer test.
8. HRL landmark-control probe as a secondary result or limitation.

This structure preserves a recognizable scientific contribution even if the
current goal-conditioned worker remains imperfect. It also makes outside work
useful as comparison and inspiration without allowing it to replace the
specific DG/CA3 sequence-feedback hypothesis being tested.
