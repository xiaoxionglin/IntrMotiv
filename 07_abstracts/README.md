# Abstract drafts

The [Bernstein IntrMotiv abstract](bernstein_intrmotiv_abstract/summary.md) folder contains its source context and numbered revisions. Start with the summary to identify the selected text, then open an `iteration_XX.md` file for a historical draft. For the underlying findings, use the [experiment status map](../06_experiments/README.md).

For COSYNE 2027, use the [submission asset index](cosyne_2027_submission_draft/README.md) to find the selected figures and the [reusable visual asset index](cosyne_2027_submission_draft/REUSABLE_ASSETS.md) to find standalone plots, icons, field atlases, trajectories, and their source tables for later papers or talks.
