# Abstract drafts

The [Bernstein IntrMotiv abstract](bernstein_intrmotiv_abstract/summary.md) folder contains its source context and numbered revisions. Start with the summary to identify the selected text, then open an `iteration_XX.md` file for a historical draft. For the underlying findings, use the [experiment status map](../06_experiments/README.md).

For COSYNE 2027, the submission folder keeps writing, selected artwork, and
their retained sources together. Choose the owner by what you want to revise:

| Material | Owner and role |
| --- | --- |
| Manuscript text | [`main.tex`](cosyne_2027_submission_draft/main.tex) is the editable manuscript source; [open questions](cosyne_2027_submission_draft/OPEN_QUESTIONS.md) tracks claim and length checks |
| Earlier writing | [`drafts/`](cosyne_2027_submission_draft/drafts/) holds the outline, evidence-linked draft, dated prose, and discussion notes; the [draft index](cosyne_2027_submission_draft/README.md#earlier-writing-drafts) explains each role |
| Selected artwork and retained alternatives | [Submission asset index](cosyne_2027_submission_draft/README.md) identifies the selected figures and why distinct variants remain |
| Standalone visuals and their source tables | [Reusable visual asset index](cosyne_2027_submission_draft/REUSABLE_ASSETS.md) routes to plots, icons, field atlases, and trajectories |
| Underlying scientific evidence | [COSYNE evidence and run index](../06_experiments/cosyne_2027/README.md) owns the report reading order and links the canonical analysis outputs |

Overleaf ZIPs in the submission folder are generated handoff copies. Revise the
source files above, then regenerate and check a package before sharing it; a ZIP
or compiled PDF is not the owner of manuscript text, evidence, or figure edits.
