# COSYNE 2027 submission layout draft

Open [main.pdf](main.pdf) to review the two-page layout. Page 1 contains the author's latest GitHub title and 312-word abstract (not yet shortened to COSYNE's 300-word limit), the original-size architecture, and a compact illustration of the three policy families. Page 2 groups every selected result plot by claim, retains the provisional temporal-hit panel, and adds an explanatory strip for evaluation inputs, hit timing, and planned goal control. [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) records claim checks and analyses for discussion.

Upload cosyne_2027_overleaf_sources.zip as a new Overleaf project and set main.tex as the main document. The updated ZIP is a compact, self-contained version: it contains the three figure PDFs actually used by `main.tex`, their original SVG sources, submission notes, and panel provenance. FIGURE_OPTIONS.md indexes the included figures. Rendering scripts and underlying CSV inputs remain in the full repository; the earlier full candidate-library ZIP is preserved as `cosyne_2027_overleaf_sources_full_backup_20261012.zip` in this directory. The backup predates this figure revision, while the compact ZIP contains the current panels. `build_overleaf_package.py` refreshes the compact ZIP by default; `--full` writes a separate expanded candidate-library ZIP without replacing it. Raw NEMO2 evaluator arrays are deliberately excluded; PANEL_PROVENANCE.json lists the verified source hashes.

The composite was rendered at its final 7.5-by-5.30-inch print size using scalable Arial with 9–10 pt labels. Individual dot-plot widths are 1.43 inches (behavior), 0.86 inches (DG), 1.20 inches (decoder), and 1.10 inches (worker). Open squares show controls, filled circles show tested conditions, and a line links the same training seed; the plots use actual values rather than a difference axis. The bottom strip distinguishes identical-observation DG tests from policy rollouts, sketches hit timing, and labels the commanded-versus-actual-goal comparison as planned. It contains no additional results. The selected example was extracted from two SHA-256-verified evaluator arrays into lightweight peak coordinates and an occupancy mask. The full source plots remain available in the repository and the backed-up candidate library for later selection.
