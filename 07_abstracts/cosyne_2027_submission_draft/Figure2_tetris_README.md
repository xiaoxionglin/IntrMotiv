# Figure 2 construction SVG

[Figure2_tetris.svg](Figure2_tetris.svg) is a source stage for [Figure2_story.svg](Figure2_story.svg), which in turn supplies the selected palette and layout pipeline. It is retained because `build_figure2_story.py` reads this SVG. Its former PDF/PNG exports and empty-slot sidebar layout were removed as superseded whole-figure trials. [build_figure2_tetris.py](build_figure2_tetris.py) can regenerate them if layout work resumes.

The construction stage starts from the author's [original canvas](Figure2_fiddle.svg), preserves the individual result plots, and embeds three DG maps from the C15 temporal-credit seed-123 terminal model. The maps are illustrative and do not enter paired statistics. The [full atlas index](figure1_candidates/full_place_field_atlases.md) and [story-figure notes](Figure2_story_README.md) give the scientific context for the retained Figure 2 variants.
