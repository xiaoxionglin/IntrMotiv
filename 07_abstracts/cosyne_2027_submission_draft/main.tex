\begin{center}
{\large\bfseries Spatial coding emerges from event timing in a hippocampus-inspired navigation agent\par}
\end{center}
\vspace{-5pt}
In a novel environment, animals can develop spatial representations without being told where they are. Could the timing of sensory experience help create such a code? We study a hippocampus-inspired agent that navigates a visual world using only its own observations. Sparse dentate gyrus (DG) responses mark sensory events, while a CA3-like sequence memory retains their recent history. The time between events supplies two learning signals: a ``push'' that strengthens events following long intervals, and a ``pull'' that rewards actions reaching a selected event sooner. Neither signal supplies coordinates or physical distances.

DG responses become spatially informative as the agent explores. Yet the apparent code also depends on behavior: random actions make spatial maps less informative and less reliable even when the trained network is unchanged. To test learning itself, we replay identical observations through networks trained with temporal or constant DG credit. Temporal credit yields less overlapping response maps in every matched comparison and more widely distributed field peaks in most, although gains in spatial information vary across goal settings. Changing temporal credit to the policy has less consistent effects on DG maps, while one goal strategy stores more reliable event transitions. Thus, event timing can organize a spatial code, and the paths an agent takes affect how clearly that code is expressed.

\textbf{Event timing and spatial structure.} The same event interval can arise from direct movement, detours, or pauses, so its relationship to physical distance depends on behavior. Movement links what the agent sees to when DG events occur. DG spatial information grows during training across all three goal settings, and individual DG units develop localized responses (Fig.~\ref{fig:architecture}B,C). These online observations alone cannot separate changes in the network from changes in the places its policy visits.

\textbf{Behavior changes the code we observe.} Goal-conditioned agents travel more efficiently than the agent without goals, producing different streams of experience (Fig.~\ref{fig:results}A). We then hold each trained network fixed and change only its actions. Learned actions produce higher DG spatial information in 36 of 38 models and more reliable spatial maps in 37 of 38 than random actions (Fig.~\ref{fig:results}B). Thus, behavior affects the spatial signal expressed by a fixed network; this test does not establish how behavior shaped its weights during training.

\textbf{Temporal push separates DG responses.} To isolate a learned change in the DG representation, we compare temporal credit with mean-matched constant credit on identical observations (Fig.~\ref{fig:results}C). Temporal credit reduces overlap among DG maps in all 15 matched pairs and spreads their field peaks across more of the visited environment in 13. Spatial information rises in all five no-goal pairs, but less consistently with goal conditioning. The clearest effect is therefore a less redundant, more spatially distributed code, rather than a uniform increase in information per unit.

\textbf{Temporal pull has a different outcome.} Changing target-hit credit from constant to temporal produces mixed changes in DG spatial measures (Fig.~\ref{fig:results}D). With frontier-selected targets, reliable stored event transitions increase in all five matched pairs; the uniform-goal results are mixed. These measurements use each policy's own path, so they cannot isolate a change in DG coding on fixed input. Stored transitions also do not show whether the agent physically reached a commanded goal. The behavioral meaning of the pull effect remains open.
