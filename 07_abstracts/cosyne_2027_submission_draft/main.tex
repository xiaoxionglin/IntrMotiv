\begin{center}
{\large\bfseries Spatial representations emerge from optimizing temporal separation of activations in a hippocampus-inspired navigation agent without spatial supervision}\par
\end{center}
\vspace{-5pt}
When animals are put into a novel environment, they typically have no prior expectations about spatial contingencies such as reward locations or task requirements. Nevertheless, the hippocampus in mammals quickly builds a spatial representation within the first exposure.  How can spatial representations emerge from sensory inputs and learning objectives that do not explicitly encode space? We investigate this question using a bottom-up computational architecture inspired by hippocampal physiology, exploring whether spatial organization can arise from the temporal structure of sensory experience and self-generated behavior, without position labels, path integration, maps, or spatial rewards.

We therefore simulate an artificial agent in a virtual environment receiving exclusively egocentric input. The actions of the agent are generated by a model that combines dentate gyrus (DG)-like sparse sensory events with CA3-like sequences implementing a memory buffer. CA3 records the temporal separation (TS) between DG events, that provides two complementary learning signals: a \textbf{``push''} signal that encourages DG events to have more TS, shaping their place fields to be distinct; and a \textbf{``pull''} signal that rewards faster transition policy between DG events, such that the TS becomes a better proxy of navigational distance. Employing the model, exploration of a continuous visual environment leads to the emergence of spatially informative DG activity  without explicit information about its physical location or spatial distances.
%224 words until here
We explore the contribution of behavior and different pathways of the TS signal to the place code using an ablation approach and find that TS-weighted learning specifically for the push signal produces higher DG spatial information, less redundant response maps, and a broader spatial distribution of field peaks.

Together, our results demonstrate how spatial coding can emerge from the self-generated behavior, TS-weighted learning, and sequential memory, without explicitly optimizing for spatial information.

\textbf{Learning objectives.} We use temporal separation ($TS_{i\to j}$), measured in policy decisions between eligible DG events, as an intrinsic learning signal. The architecture and two complementary learning objectives are:

\begingroup
\vspace{-17pt}
\setlength{\abovedisplayskip}{3pt}
\setlength{\belowdisplayskip}{3pt}
\begin{gather}
u_t=[\mathrm{BN}(Wf(o_t))-\tau]_+,\quad x_{t+1}=Ax_t+Bu_t,\quad (\pi_t,V_t)=D_\theta(x_t,d_t)
\label{eq:architecture}\\[-3pt]
\mathcal L_{\mathrm{DG}}(W)=-\mathrm{sg}(TS_{i\to j})u_{t,j},\quad
\mathcal L_{\mathrm{policy}}(\theta)=-\mathbb E_{\mathcal T\sim\pi_\theta}\left[\textstyle\sum_t\gamma^t(L-TS_{i\to j_t})\right]
\label{eq:objectives}
\end{gather}
\endgroup


In Eq.~\eqref{eq:architecture}, $f(o_t)\in\mathbb{R}^{3840}$ denotes visual features, $W$ the trainable DG projection, $\mathrm{BN}$ batch normalization, and $\tau=2.43$ the sparsification threshold. The DG activity $u_t\in\mathbb{R}^{16}$ drives a CA3 shift register with $L=71$ memory length per DG unit, giving a flattened CA3 state of $x_t\in\mathbb R^{L\cdot16}$. Fixed matrices $A$ and $B$ implement sequential shifting and DG input injection (to the first 8 slots in each sequence independently; 2 visualized in~\ref{fig:architecture}), respectively. The learned MLP readout $D_\theta$ receives CA3 state $x_t$ and egocentric depth $d_t\in\mathbb{R}^{1\times10}$ mimicking whisking sensation.


In Eq.~\eqref{eq:objectives}, the DG \textbf{``push''} reinforces eligible event activity $u_{t,j}$ proportionally to the preceding interval $TS_{i\to j}$, with $\mathrm{sg}$ denoting stop-gradient. Conversely, the policy \textbf{``pull''} rewards shorter event intervals relative to the CA3 memory length $L$, optimizing discounted intrinsic return, with advantage actor--critic and PPO modifications.


These opposing pressures may exploit the relationship between movement and event timing to organize DG activity spatially, without explicitly optimizing physical distances.

\textbf{Spatial emergence and exploration.} DG spatial information rises during training in all three agent designs (Fig.~\ref{fig:architecture}B), and example FG response maps illustrate localized activity (Fig.~\ref{fig:architecture}C). The NG, UG, and FG agents follow different trajectories; in terminal online windows, the goal-conditioned agents show higher mean path efficiency than NG (Fig.~\ref{fig:results}A). These observations establish spatial coding during exploration, but the online curves combine changes in the networks with changes in the paths they sample.

\textbf{Behavior-dependent expression.} With each network frozen, learned actions yield higher DG spatial information than uniform random actions in 36 of 38 terminal models and higher split-half DG-map reliability in 37 of 38 (Fig.~\ref{fig:results}B). Behavior therefore changes the spatial code expressed by a fixed network. Because the action policies produce different sensory sequences, this comparison does not isolate a fixed-input change or show how behavior shaped the network during training.

\textbf{Temporal DG push.} We compare temporal DG credit with mean-matched constant credit across five matched seeds per design, replaying the same 10,001 observations through each pair of trained networks (Fig.~\ref{fig:results}C). Temporal credit increases DG spatial information in all five NG pairs (mean $+0.0575$ bits per decision), four UG pairs, and three FG pairs. It reduces overlap between DG response maps in all 15 pairs and broadens eligible field-peak coverage in 13. Thus, the clearest effect of temporal push is a less redundant, more spatially distributed DG code on common input. Reliable stored-graph edge counts, measured on separate policy-driven paths, do not change consistently.

\textbf{Temporal policy pull.} In a separate high-policy-credit comparison, we vary temporal versus constant target-hit credit while keeping temporal DG credit fixed in UG and FG (Fig.~\ref{fig:results}D). Across five matched seeds per design, DG spatial information, map overlap, and peak coverage show mixed effects. FG gains reliable stored-graph edges in all five pairs, while UG edge changes are mixed. These representation and graph measurements use each policy's own trajectory, and the pull cohort uses $\gamma=0.999$ and GAE $\lambda=0.995$ rather than the push cohort's policy-credit setting. Stored edges indicate detector-memory structure, not physical arrival at commanded goals.
